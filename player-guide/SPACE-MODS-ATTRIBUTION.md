# ATM10 Space Mods Bundle Attribution

This bundle contains the extra client mods needed for the ATM10 space server.
Install ATM10 version 7.0 first, then unzip the bundle and copy the `.jar`
files into the ATM10 profile's `mods` folder.

Included files:

| Project | Version | File | License | Source |
|---|---:|---|---|---|
| Stellaris | 1.4.23 | `stellaris-1.21-neoforge-1.4.23.jar` | CC-BY-NC-SA-4.0 | <https://modrinth.com/mod/stellaris> |
| Architectury API | 13.0.8+neoforge | `architectury-13.0.8-neoforge.jar` | LGPL-3.0-only | <https://modrinth.com/mod/architectury-api> |
| Potentials | 0.7.1 | `potentials-neoforge-1.21-0.7.1.jar` | MIT | <https://modrinth.com/mod/potentials> |

The files are redistributed unmodified for server players to connect to this
private Minecraft server. Project authors retain their respective copyrights.
