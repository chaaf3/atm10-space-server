# ATM10 Space Server Player Setup

Use this guide to install the client pack and send the right Minecraft username for the whitelist.

## What You Need

- Minecraft: Java Edition on the Microsoft account you play with.
- CurseForge app installed from <https://www.curseforge.com/download/app>.
- At least 16 GB of computer RAM. 32 GB is better.
- The server address from the server admin.
- The extra space mod bundle from GitHub: [ATM10-Space-Mods.zip](https://github.com/chaaf3/atm10-space-server/blob/main/player-guide/ATM10-Space-Mods.zip?raw=1).

## Install the Modpack in CurseForge

1. Open the CurseForge app.
2. Choose Minecraft.
3. Search for All the Mods 10 - ATM10.
4. Install ATM10 version 7.0.
5. Do not update the modpack unless the server admin says the server has been updated.

## Add the Space Mods

1. In CurseForge, click the ATM10 profile.
2. Open the profile menu, usually shown as three dots.
3. Choose Open Folder.
4. Open the mods folder.
5. Download the space mod bundle: [ATM10-Space-Mods.zip](https://github.com/chaaf3/atm10-space-server/blob/main/player-guide/ATM10-Space-Mods.zip?raw=1).
6. Unzip `ATM10-Space-Mods.zip`.
7. Copy the `.jar` files from the unzipped bundle into the `mods` folder.
8. Do not unzip the `.jar` files themselves.
9. Launch the pack from CurseForge.

The extra files are expected to include Stellaris and its required dependencies. Use only the files from the admin or the exact download links they provide. Mismatched mod versions can prevent you from joining.

## Allocate Memory

Set CurseForge memory for this profile:

- 16 GB computer RAM: allocate 8-10 GB.
- 32 GB or more computer RAM: allocate 10-12 GB.

Do not allocate all of your RAM. Your operating system still needs room.

## Join the Server

1. Launch ATM10 from CurseForge.
2. Choose Multiplayer.
3. Add the server address from the admin.
4. Join the server.

If you see a whitelist error, send the admin your Minecraft Java username exactly as shown in your Minecraft profile.

## Whitelist Request

Send the admin only this:

```text
Minecraft Java username: YourNameHere
```

Do not send your Microsoft email, password, Discord name, or Xbox gamertag unless it is also your Java username.

Minecraft Java usernames are usually 3-16 characters and contain only letters, numbers, and underscores.

Examples:

```text
Minecraft Java username: CoolPlayer_27
Minecraft Java username: StoneBuilder
```

## Quick Troubleshooting

If CurseForge launches the wrong Minecraft version, launch directly from the ATM10 profile inside CurseForge.

If Minecraft crashes during startup, increase allocated memory within the recommended range and try again.

If the server says mod mismatch, reinstall ATM10 version 7.0 and replace the extra space mod files with the exact files from the admin.

If the server says not whitelisted, double-check your Minecraft Java username and send it again.

If multiplayer authentication fails, restart Minecraft and make sure you are signed into the Microsoft account that owns Java Edition.
